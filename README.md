# ML-Book-Review-Sentiment-Analysis

## Project Overview
This project implements a machine learning model to classify book reviews as positive or negative sentiment using NLP techniques.

## Problem Definition
- **Task**: Binary sentiment classification (Positive/Negative)
- **Data**: Book review dataset with text reviews and sentiment labels
- **Model**: Neural Networks

## Dataset
The dataset contains:
- 1,973 book reviews
- Binary labels: True (Positive) / False (Negative)
- Slight class imbalance: 47.5% Negative vs 52.5% Positive
